# Design System

## Colors
- Paper: `#f4f4ec`
- Ink: `#171b17`
- Lime accent: `#d3ff43`
- Forest green: `#173d2c`
- Muted: `#686e64`

## Typography
- Display: Space Grotesk
- Body: Manrope
- Mono / labels: DM Mono

## Motion
- Soft hover lift (`translateY(-3px to -7px)`)
- Card tilt via CSS custom properties + pointer events
- Marquee infinite scroll for tech strip
- Progress bar tied to scroll position

## Spacing & radius
- Large radius: 22–26px for cards
- Generous section padding (~105px)
