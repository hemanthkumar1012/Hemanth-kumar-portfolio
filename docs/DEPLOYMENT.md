# Deployment

This site is published via GitHub Pages from the `main` branch.

1. Push to `main`
2. GitHub Actions (if configured) or Pages settings serves the root
3. Live URL: https://hemanthkumar1012.github.io/Hemanth-kumar-portfolio/

Ensure `.nojekyll` is present so Jekyll does not process the site.

Custom domain (optional) can be set in repository Settings → Pages.
