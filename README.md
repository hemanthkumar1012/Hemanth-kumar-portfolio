# Hemanth Kumar — Advanced Portfolio

**Live site:** [hemanthkumar1012.github.io/Hemanth-kumar-portfolio](https://hemanthkumar1012.github.io/Hemanth-kumar-portfolio/)

A premium, editorial-style portfolio showcasing AI products, full-stack applications, and developer tools built by Hemanth Kumar.

## Features

- Responsive editorial design with custom typography (Space Grotesk, Manrope, DM Mono)
- Interactive project cards with hover tilt, filters, and animated art windows
- Smooth scroll navigation, progress bar, and section-aware active links
- Capability cards, process timeline, and journey / education sections
- Floating product window mock + marquee tech strip
- SEO meta tags, Open Graph, and Twitter cards
- Accessible focus states and reduced-motion friendly animations
- GitHub Pages deployment with `.nojekyll`

## Tech

- Pure HTML5 / CSS3 / Vanilla JavaScript (no framework bloat)
- Custom CSS design system (lime / forest green palette)
- IntersectionObserver for scroll reveals and nav highlighting
- Pointer-driven 3D tilt effects on cards

## Projects highlighted

ApplyRight · ParcelPilot AI · LLM Evaluation Lab · AgentGuard · SevaSetu · Cricket Tournament System · and more.

## Local development

Just open `portfolio-v2.html` (or the redirected `index.html`) in a browser. No build step required.
